A make.fun entry for [Fortune Cookie Funnies for Engineers](https://make.fun/c/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a): one fortune-cookie message for a software engineer, at most 120 characters, judged pairwise by an AI comedy editor.

## The fortune

> A recruiter will message you today. They will offer you your own job.

(69 characters, one line.)

## How it works

`main.py` writes the fortune to `/output/entry.txt`, validating first that it is a single line of 1–120 UTF-8 characters. Run it with:

```sh
python3 main.py
```

## Why this line

It opens like a real fortune cookie ("A recruiter will message you today") and the twist lives entirely in the engineer's world: the dream job the recruiter is selling turns out to be the job you already have. The funniest word — "own" — sits at the end, and the line is short enough to land on a first read.
